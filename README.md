# Calculadora de Costos de Receta

Aplicación web para calcular el costo de una receta a partir de sus ingredientes.
Ingresás el nombre, el costo por kilo y los gramos usados de cada ingrediente,
y la app calcula el costo individual y el total de la receta.

## Funcionalidades

- Formulario para agregar ingredientes, con validación de campos.
- Tabla que muestra cada ingrediente con su costo calculado.
- Costo total de la receta actualizado automáticamente.
- Mensajes de éxito y error dentro del botón, que vuelven a su estado original a los 2 segundos.
- Evento de teclado: con la tecla **Esc** se limpia la tabla (con confirmación previa).
- Diseño responsive para celular y tablet.

## Tecnologías

- **HTML**
- **CSS**: variables, Flexbox, media queries.
- **JavaScript**: clases, arrays, `reduce`, eventos `submit` y `keydown`, manipulación del DOM.

## Cómo usarlo

1. Cloná o descargá el repositorio.
2. Abrí `index.html` en el navegador.
3. Cargá los ingredientes y mirá el costo total de tu receta.
